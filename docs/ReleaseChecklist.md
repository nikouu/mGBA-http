# Release Checklist

Ensure the following are done, if needed, before each release.

- Version incremented
	- csproj
	- Lua header
- Lua file is set to log level 2
- All tests pass including mGBA integration tests
- CI is green
- Readme updated
- Implemented API doc updated
- Examples doc updated
- Full Guide doc updated
- Lua Guide doc updated
- GitHub Pages docs deployed
- Binaries published with latest .NET version
- A published binary starts and serves
- Create the list of changes for the release notes
- Update Scalar JS package if .NET package updated
